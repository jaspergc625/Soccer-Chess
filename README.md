# Soccer Chess

https://jaspergc625.github.io/Soccer-Chess/

All feedback is welcome.

The GitHub repo page is the source code. Open the link above to play in the browser.

## Play locally

1. Install [Node.js](https://nodejs.org/)
2. In this folder, run `start.bat` (or `node server.js`)
3. Open the URL it prints, usually `http://localhost:3000/`
